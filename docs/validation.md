## 第二个案例：109 双耳支架

该案例使用另一张用户提供的工程图，包含底板、弯折立壁、中心凸台、双腹板和耳孔。原工作模型通过单实体、重建和几何检查（0 错误），最终 R6 圆角 API 读回半径为 6.0 mm。详细资料见 [案例说明](drawing109.md) 和 [脱敏验证摘要](demo/drawing109/validation.json)。

R6 最初因候选边包含后槽口边而停止，经只读测量和局部修复完成。随后使用修正后的公开案例脚本从空白零件完整重放：12 组特征一次运行全部通过，耗时 110.69 秒；重建通过、实体数 1、几何错误 0，R6 再次读回为 6.0 mm。见 [重放日志](demo/drawing109/replay-log.json)。

[自动建模录像](demo/drawing109/automated-build-2x.mp4) 为这一完整运行的连续窗口采集，原始录制约 114 秒，公开版仅压缩并加速至 2 倍速（约 56 秒），无模型操作剪辑。录制检查与入口哈希见 [录制信息](demo/drawing109/recording.json)。之前的成品旋转展示不能替代这段过程录像。

案例图纸验收仍为 `AWAITING_USER_REVIEW`；该次从零重放不代表完整尺寸及剖面验收，也不代表跨机器运行验证。
