# v1.2.0 — 阀体案例与倒角验证改进

新增 LJT06.06 阀体案例，公开原始二维图纸、SolidWorks 原生模型、预览、建模脚本、尺寸合同及验证摘要。仓库现有弯头、支架和阀体三个零件案例；各案例的验证范围分别记录。

## 修复与改进

- 修正实体倒角 API 类型编号，拒绝无效参数及未生成面的特征；失败时不再静默替换用户指定角度。
- 加强局部几何验证：检查实际生成面、尺寸和材料移除结果，不以特征名称或接口返回成功代替几何证据。
- 明确保留现有颜色、外观、材质与场景，未经用户要求不修改。
- 识图时先放大细节并交叉核对视图，再判断尺寸或位置证据是否缺失。

## 已验证与边界

- 倒角封装 4 组代码测试通过；独立 SolidWorks 孔口 C1 实测的径向和轴向尺寸均为 1 mm，材料移除量与理论值一致。
- 已保存阀体重建成功、单实体、未检测到特征错误；24 处孔口 C1 已实测，15 个已测圆角曲面半径为 R3。
- 阀体仍为 `AWAITING_USER_REVIEW`：完整剖面验收、修复后从零重放和自动建模过程录像尚未完成。M36/M8 为装饰螺纹；局部检查不代表所有未注圆角均已验收。
- 本次证据不代表 MCP 全链路、跨机器复现或任意图纸转换能力已通过验证。
